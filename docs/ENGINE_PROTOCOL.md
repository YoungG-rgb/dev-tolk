# Протокол tolk-engine

Состояние на 2026-10-18. Описаны команды `probe` и `extract` (MVP-008). Команда `transcribe` и формат `original.json` добавляются в MVP-009.

## Общие правила

- Движок — отдельный процесс (TD-04). Приложение запускает его на каждую операцию.
- Результат — **JSON Lines в stdout**: одно событие на строку, UTF-8, у каждого есть поле `type`. Последняя строка — итог (`probe`, `done` или `error`).
- stderr — только диагностика для журнала (например, сообщение о panic). Тексты транскриптов туда не пишутся.
- Пути передаются аргументами и могут содержать кириллицу и пробелы.
- Исходный файл никогда не изменяется. Выходной файл не может совпадать с входным (код `USAGE`).

## Коды возврата

| Код | Значение |
|---|---|
| 0 | успех |
| 1 | внутренняя ошибка (`INTERNAL`), включая panic |
| 2 | неверные аргументы (`USAGE`) |
| 10 | проблема с входным файлом (`FILE_NOT_FOUND`, `ACCESS_DENIED`, `UNSUPPORTED_FORMAT`, `UNSUPPORTED_CODEC`, `NO_AUDIO_TRACK`, `CORRUPT_FILE`) |
| 11 | не удалось записать результат (`OUTPUT_FAILED`, нет места или каталога) |

Если доступа нет к выходному каталогу, код ошибки `ACCESS_DENIED`, код возврата 10.

## Событие `error`

```json
{"type":"error","code":"UNSUPPORTED_CODEC","message":"Кодек аудио не поддерживается: AC-3","codec":"AC-3"}
```

`codec` присутствует только для `UNSUPPORTED_CODEC`. `message` — готовый текст на русском, но приложение сопоставляет сообщения по `code` (MVP-018, MVP-025).

| `code` | Когда |
|---|---|
| `USAGE` | неверные аргументы; выходной файл совпадает с входным |
| `FILE_NOT_FOUND` | входной файл не найден |
| `ACCESS_DENIED` | нет доступа к входному файлу или каталогу результата |
| `UNSUPPORTED_FORMAT` | контейнер не распознан (не медиафайл, неизвестный контейнер, смена частоты в файле) |
| `UNSUPPORTED_CODEC` | у файла есть аудиодорожки, но ни для одной нет декодера |
| `NO_AUDIO_TRACK` | в файле или видео нет аудиодорожки |
| `CORRUPT_FILE` | файл пуст, оборван (нет индекса MP4), не читается или содержит звук, который не удалось декодировать |
| `OUTPUT_FAILED` | не удалось записать результат |
| `INTERNAL` | внутренняя ошибка |

## `tolk-engine probe <файл>`

Читает контейнер, звук не декодирует. Если длительность не указана в заголовке (MP3 без Xing), просматривает пакеты без декодирования.

```json
{"type":"probe","container":"isomp4","codec":"AAC","duration_ms":3600023,"sample_rate":44100,"channels":1,"has_video":true}
```

`duration_ms`, `sample_rate` и `channels` могут быть `null`, если контейнер их не сообщает. `container` — короткое имя демультиплексора Symphonia (`mp3`, `isomp4`, `ogg`, `matroska`, `flac`, `wave`). `has_video` — есть ли видеодорожка. Выбирается первая аудиодорожка с поддерживаемым кодеком (дорожка по умолчанию — в приоритете).

## `tolk-engine extract <файл> <out.wav>`

Декодирует аудио или аудиодорожку видео в WAV 16 кГц, моно, 16 бит. Видеопоток не декодируется. Запись атомарная: данные пишутся во временный файл `.tolk-extract-*.part` в каталоге результата, затем файл переименовывается в `out.wav`. При ошибке и при завершении процесса итогового файла нет. Временный файл при принудительном завершении процесса остаётся: приложение очищает свой `tmp/` при старте (MVP-015). Поэтому в `out.wav` нужно передавать путь в каталоге, который приложение чистит.

События:

```json
{"type":"progress","percent":0}
{"type":"progress","percent":37}
{"type":"progress","percent":100}
{"type":"done","output":"/path/out.wav","duration_ms":3600000,"samples":57600000,"incomplete":false,"skipped_packets":0}
```

- `progress` — целые проценты, не убывают, только если длительность известна; события `0` и `100` есть всегда. Процент считается по входной длительности, а не по выходной.
- `done.incomplete = true` — результат заметно короче заявленной длительности (больше 1 с и больше 3%): файл оборван или частично повреждён. Выдано всё, что удалось прочитать. Приложение должно предупредить пользователя, а не отклонять файл.
- `done.skipped_packets` — число недекодированных пакетов (повреждённые участки). Если таких больше 20% — ошибка `CORRUPT_FILE`.
